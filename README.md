# HE3D K280 Build
 Building my K280


I've included my working build of Marlin and the samples that I've used to create this build.  I have been using a portable version of Arduino 1.8.5 to perform edits and flash as newer versions tend to catch errors that smarter people than me could probably fix.

Arduino 1.8.5 can be found here
https://github.com/arduino/Arduino/tree/1.8.5
